## 📖 Overview

**Billing System** is a standalone, database-backed application for small-scale stores and supermarkets.
It stores and manages the day-to-day data a store generates, such as customer, billing, employee, and product
details. It also keeps sales records that can be retrieved by month or year.

The goal is a simple, reliable way to handle the large number of transactions a store processes every day
and to keep that data organised and accessible.

---

## ✨ Features

| Module | What it manages |
| :--- | :--- |
| 👤 **Customers** | Customer details and records |
| 🧾 **Billing** | Bill generation and billing details for each transaction |
| 🧑‍💼 **Employees** | Employee details |
| 📦 **Products** | Product details and inventory information |
| 📊 **Sales Records** | Sales history, retrievable by month and year |

## 🚀 Getting Started

1. **Clone the repository**
```bash
   git clone https://github.com/Pranavrd2001/DBMS-Mini-Project---Billing-System.git
```
2. **Install the application**: open the `Application` folder and run **`setup`**.
3. **Launch** the installed Billing System and start managing store data.

> 💡 To explore or modify the code, open the project from the `Source Code` folder in **Visual Studio 2017**.
